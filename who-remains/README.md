# Who remains

Planned data-encryption and compact data-management system. It is intended to combine versioning and binning methods that reduce data transfer latency, transfer loss, and overall data volume while keeping data easy to manage.

It is designed to serve Abracadabra and application-specific systems such as stamp.dev.

**Status:** Planned concept — no repository or implementation created yet.
